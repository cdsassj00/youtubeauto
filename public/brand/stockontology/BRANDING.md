# 주식온톨로지 채널 브랜딩 (ch2 재개편안)

기존 "쓸모의 발견"(구독자 0 · 총 조회수 9 · 영상 6편)을 갈아엎어 쓴다.
지킬 구독자가 없어 리브랜딩 비용이 사실상 0이므로, 채널을 새로 파지 않고 이름·핸들·이미지만 바꾼다.

## 1. 이름·핸들

| 항목 | 값 |
|---|---|
| 채널명 | **주식온톨로지** |
| 핸들 | `@stockontology` (선점됐으면 `@stockontology_cc`) |
| 사이트 | https://stockontology.cc |

★"스톡"이 아니라 "주식"인 이유★ stockontology 의 우리말 그대로라 사이트와의 연결은
유지되면서, 외래어 한 단어를 덜 거친다. "스톡"은 읽고 한 번 더 생각해야 하는데 "주식"은
바로 읽힌다. 검색에서도 훨씬 흔히 쓰이는 낱말이다.
핸들은 라틴 문자로 두어 사이트 주소와 맞춘다. 배너에는 위쪽에 `STOCKONTOLOGY` 를
자간을 벌려 얹어, 한글 이름과 영문 도메인이 한 화면에서 이어지게 했다.

"온톨로지 데일리" 같은 부제는 채널명이 아니라 재생목록 이름으로 쓴다.

## 5. 영상 제목 규칙 ★가장 중요★

본 채널 실측: 자체 용어가 앞에 오는 제목은 조회 50~100회, 고유명사·검색어가 앞에 오는 제목은 2,900~7,100회.

- **날짜를 맨 앞에 쓰지 않는다.** 아무도 날짜로 검색하지 않는다. 날짜는 맨 뒤.
- **첫 15자 안에 종목명 또는 업종명이 온다.**
- API의 `titleSuggestion`은 참고만 하고 우리가 다시 쓴다.

```
✗ 2026-08-19 온톨로지 데일리 — 위험선호 국면 — 순풍 확산 · SK케미칼 외 4종목
✓ 정유화학에 순풍이 붙었습니다 | SK케미칼·SK이노베이션·GS (8/19 한국)
✓ 유가 2% 오르자 계산이 가리킨 5종목 (8/19 한국장 전)
✓ 에너지가 다시 1등 | Chevron·ConocoPhillips (8/19 미국장 마감)
```

어제 채점(`previous`)이 붙는 날은 그게 더 센 제목이다:
```
✓ 어제 추천 5종목, 오늘 결과입니다 (적중 3/5 · 평균 +1.8%)
```

## 8. 썸네일

`brief-card.svg` 를 그대로 쓰지 않는다 — 정보가 많아 유튜브 목록에서 글자가 안 읽힌다.
카드는 영상 본편 화면으로 쓰고, 썸네일은 따로 만든다.

- 큰 글씨 **한 덩어리**(4~7자): `정유화학 순풍` / `유가 +2%` / `적중 3/5`
- 배경은 카드에서 잘라낸 인과 그래프 일부(흐리게)
- 좌하단에 날짜 작은 글씨, 우상단에 KR/US 배지
- 시리즈 통일감은 골드 띠 하나로만 준다

## 9. 소개영상 (한 편, 채널 트레일러로 고정)

1. "AI한테 주식 사이트를 만들어 달라고 했고, 진짜 돈을 맡겼습니다"
2. 유가 → 정유화학 → SK이노베이션 화살표 (사이트 3D 화면 녹화)
3. 4개 전략이 같은 조건으로 경쟁하는 전략실 리그
4. **백테스트 +112.5%, 실계좌 -4.03%** — 이 대비가 이 채널의 유일무이한 자산
5. 손절 기록 화면 — "실패도 지우지 않습니다"
6. 정직성 원칙 + 면책

## 10. 적용 순서

1. 스튜디오에서 채널명·핸들 변경 (핸들은 14일에 2회 제한)
2. `profile.png` 수동 업로드
3. branding 워크플로로 배너·워터마크·설명 적용
   `{"password":"...","event":"branding","channel":"ch2","apply_description":true}`
4. ch2 `YOUTUBE_DESC_FOOTER` 를 이 채널 문구로 교체
5. 기존 영상 6편은 비공개 전환 검토 (주제가 다르고 지속률 2~24%로 낮다)
6. 소개영상 1편 → 그다음 데일리 자동 발행

★3번은 되돌리기 번거로운 outward 작업이다. 사용자가 명시적으로 지시할 때만 실행한다.★
