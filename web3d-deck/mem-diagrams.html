DRAM CELL — 1T1C

D램 한 칸은 트랜지스터 1개와 캐패시터 1개다

셀 하나가 1비트. 8기가바이트 모듈에는 이 구조가 약 640억 개 들어간다.
캐패시터의 전하는 시간이 지나면 새어나가고, 그러면 1이 0으로 바뀐다.
REFRESH

그래서 D램은 64밀리초마다 전체를 다시 쓴다

전원이 들어와 있어도 가만히 두면 데이터가 사라진다.
이것이 D램(Dynamic RAM)의 이름에 'Dynamic'이 붙은 이유다.
DDR — DOUBLE DATA RATE

DDR은 클럭의 오르내림 양쪽에서 데이터를 보낸다

같은 클럭에서 2배를 보낸다. 그래서 단위가 MHz가 아니라 MT/s(초당 전송 횟수)다.
BANDWIDTH — 실제 계산

대역폭은 곱셈 한 줄로 나온다

전송률데이터 폭대역폭 (모듈 1개)
DDR4-32003,200 MT/s64 bit = 8 B25.6 GB/s
DDR5-64006,400 MT/s64 bit = 8 B51.2 GB/s
전송률 × 데이터 폭 ÷ 8 = 대역폭
DDR5는 폭이 아니라 속도를 올려서 2배가 됐다. 이 방식은 곧 한계에 부딪힌다.
NAND FLASH

낸드는 전하를 절연막 안에 가둬서 전원을 꺼도 남는다

전하가 갇혀 있으므로 리프레시가 필요 없다. 대신 쓰기가 느리고, 쓰고 지우는 횟수에 수명이 있다.
MEMORY WALL

연산은 빨라졌는데 대역폭이 따라오지 못했다

DDR5 모듈 1개
51 GB/s
서버 12채널 구성
614 GB/s
HBM3E 스택 1개
1,229 GB/s
HBM4 스택 1개
2,048 GB/s
LLM이 토큰을 하나 만들 때마다 가중치 전체를 메모리에서 읽어온다.
이 구간에서 GPU 성능을 결정하는 것은 연산 능력이 아니라 대역폭이다.
HBM — 실제 단면

D램을 수직으로 쌓고, 구멍을 뚫어 연결하고, GPU 옆에 붙인다

DDR5 모듈의 신호선은 64비트. HBM4는 스택마다 2048비트 — 32배 넓은 폭이다.
폭으로 이겼기 때문에 핀당 속도를 무리하게 올리지 않아도 된다.
